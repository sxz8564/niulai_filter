# Chrome 应用商店中文listing文案

Chrome Web Store 支持按语言分别填写listing。在开发者后台给 `简体中文` 加一份翻译，
把下面的文字贴进去即可。包本身不用改。

一条原则和英文版一样：这段话是给要不要安装的人看的，不是给开发者看的。
所以不出现文件格式、接口名字、渲染或追踪的说法。技术细节留在 README 里。

角色名字保留了括号里的英文。扩展界面里显示的是英文名，中文名只是叫着亲切，
真去列表里找的时候还是得认得出来。

## 简介（Summary）

商店标题下面的那一行。

> 视频会议里顶一颗会动的动物脑袋，背景还能换成手绘的画。整个会议室的人都看得见，
> 不是只有你自己乐。

## 详细描述（Detailed description）

> 下次开会，换张脸吧。
>
> Critter Cam 把一颗会动的动物脑袋扣在你头上——牛来顶脑门，你说话它也说话。
> 因为它改的是摄像头本身，所以会议里每个人都看得见，不是只有你自己乐。
> 除了这个扩展，什么都不用装。
>
> 都有什么
>
> • 你动它就动。你往左看，它往左看；你一张嘴，它也张嘴——嘴里面都给你做出来了。
>   眨眼、笑、挑眉毛，它全学。
> • 六个角色随你挑：牛来（Niulai）和牛妈妈（NiuMama）、牛爸爸（NiuBaba）一家三口，
>   还有豹啦（Baola）、狼狼（Wolfwolf），和一只尖嘴的小鸟（XiaoNiao）。
> • 七张手绘背景。选一张，你那间屋子就彻底不见了——别人只看得到一只动物站在画里，
>   没人知道你身后到底堆了什么。
> • 想用自己的角色也行。有喜欢的 3D 模型，丢进去就出现在列表里，跟其他角色排一块儿。
> • 什么都不往外传。摄像头画面全在你自己的电脑上处理。不上传、不注册、不登录——
>   这个扩展根本不联网。
>
> 怎么用
>
> 点一下工具栏里的 Critter Cam，打开摄像头，挑一个角色。把大小和位置挪一挪，
> 盖住自己的脸，然后去开会。如果会议页面已经开着了，先刷新一下。
>
> 搭配小提示：牛妈妈配「灯笼夜」，像在过节；狼狼配「星谷」，有点酷；
> 小鸟配「颜料林」，整个人都精神了。
>
> Critter Cam 只在视频会议网站上起作用，安装的时候 Chrome 会告诉你是哪几个。
> 别的地方它什么都看不到。

和英文版一样，别在这里一个个点名支持哪些会议网站。一串品牌名在商店的垃圾内容
审核里会被当成关键词堆砌——第一次提交就是因为这个被拒的。要列举，去权限说明那一栏，
那里本来就是问你「哪些网站、为什么」。
