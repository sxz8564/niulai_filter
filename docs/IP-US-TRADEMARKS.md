# US trademark filings: Niulai, Baola, 牛来, 豹拉

A worksheet for four applications — the fields TEAS asks for, filled in as far
as they can be from this repository. Preparation notes, not legal advice.

Read the objection in the next section before paying anything. It is not a
reason to abandon the plan, but it changes which class and which basis you file
under, and getting that wrong costs the whole fee.

## The objection an examiner is likely to raise

A trademark identifies **the source of goods**. It is not simply a name you
invented and care about.

Your software is distributed under *Critter Cam*. Niulai and Baola are two of
six characters inside it, appearing as labels on rows in a picker. An examiner
looking at a specimen showing that picker can reasonably say the term names a
feature of the product rather than identifying who supplies the product — a
**failure to function** refusal, which is common for character names and is not
cured by arguing about how much the name matters to you.

Character names register comfortably in three situations:

1. **The product is named after the character.** A standalone app called Niulai
   makes NIULAI a mark for that app.
2. **Merchandise.** A plush toy, a T-shirt, a sticker sheet — the name on goods
   is a classic character trademark, and this is how nearly every cartoon
   character is protected.
3. **Entertainment services.** An ongoing series featuring the character.

None of those is what you are doing today. So:

- **Class 9 on a use basis (§1(a)) is the weak filing.** The specimen problem is
  real and you would probably be paying to find that out.
- **Intent to use (§1(b)) is the honest and stronger route.** You file now,
  which fixes your priority date at the filing date, and you have up to three
  years of extensions to put the mark into actual use before the registration
  issues. For a defensive goal this is the right instrument: it stakes the claim
  without pretending to a use that has not happened.

If a standalone Niulai app is plausible — you already have an iPhone app in
another repository — a §1(b) filing in Class 9 is defensible on its own terms.

## The four applications

Common to all four:

- **Filing basis:** §1(b), intent to use — see above.
- **Class:** 9.
- **Identification:** take it from the **Trademark ID Manual**, not free text.
  The fill-in-the-blank entry for downloadable software is what you want, along
  the lines of *"Downloadable computer software for applying animated
  three-dimensional animal characters to a live video camera image."* Using the
  Manual's pre-approved wording avoids the $200 surcharge and the goods-and-
  services office action that free text usually attracts.
- **Owner:** your legal name and domicile address. The domicile address is
  required and is what determines whether a US attorney is mandatory.

### 1. NIULAI

| Field | Value |
| --- | --- |
| Mark | NIULAI |
| Type | Standard character (protects the word in any font) |
| Translation | Not required — this is a transliteration, not English |

Note the spelling. The character is **Niulai** throughout this repository and
in the store listing; you wrote "Niula" in the request. File the spelling you
actually use, because use is what supports the mark. If you want both, they are
two marks and two fees.

### 2. 牛来

| Field | Value |
| --- | --- |
| Mark | 牛来 |
| Type | Standard character |
| Transliteration | **Required.** "Niu Lai" |
| Translation | **Required.** Literally "cow comes" / "ox arrives" |

37 CFR §2.32(a)(9)–(10) requires both a transliteration and an English
translation for non-Latin characters. You supply them; the USPTO will not
translate for you, and an application missing either gets an office action.

Be aware of the **doctrine of foreign equivalents**: the examiner will compare
the *meaning* against existing English marks, not just the characters. A mark
meaning "cow comes" is unlikely to collide with anything, but that is the test
being applied.

### 3. BAOLA

| Field | Value |
| --- | --- |
| Mark | BAOLA |
| Type | Standard character |
| Translation | Not required |

**Known prior registration:** BAOLA, Reg. 5995999 (2020), for kitchen and
household goods. Different class, unrelated goods, different buyers — it should
not block a Class 9 filing, but expect your attorney to look at it, and note
that it forecloses any later expansion into housewares.

### 4. 豹拉

| Field | Value |
| --- | --- |
| Mark | 豹拉 |
| Type | Standard character |
| Transliteration | **Required.** "Bao La" |
| Translation | **Required.** 豹 means "leopard"; 拉 means "pull". The combination has no meaning as a phrase in Chinese |

Where a combination is coined, the usual form is to translate the individual
characters and state that together they have no meaning — do not claim it means
nothing at all when the characters plainly carry meaning.

## Searches done here, and their limits

Preliminary knock-out searches only, from public sources. **Not a clearance
search**, which is what an attorney does against the live register with
phonetic, design and coexistence analysis.

| Mark | Found |
| --- | --- |
| NIULAI | Nothing apparent. A pending NIULAA — a different word — exists |
| BAOLA | Reg. 5995999, kitchen and household goods, different class |
| 牛来 | Not searched — Chinese-character marks need a proper register search |
| 豹拉 | Not searched — same |

The two Chinese marks genuinely need searching before filing, and against
transliterations as well as characters, because a registered NIULAI-alike would
be cited against 牛来 through the foreign-equivalents doctrine.

## What this does and does not buy you

Worth being clear, since the goal is defensive.

**It buys:** a priority date; a registration that makes your rights nationwide
rather than limited to where you actually trade; a presumption of validity; and
a cheap answer if someone later files the same name.

**You already have, without filing:** the right to keep using these names. The
US is first to use. Your public dated use since August 2026 is a defence
against a later filer, and the character *designs* are protected by copyright
regardless of any trademark.

So this is an upgrade rather than a rescue — worth $1,400 if you intend to
build on these characters, and worth deferring if the extension is the whole
plan. The copyright registration described in `IP.md`, at roughly $45–65 with a
deadline at the end of November, protects more of what you actually made for
about 3% of the cost. If you only do one thing, do that one.
